# The Last Hold

A tale of the Westreach: a warden, the last free town of the West, and the Host of Ash coming for it.

**Play:** https://litchfieldtyler-941.github.io/the-last-hold/

## On a phone

Open the link in Chrome, then **⋮ → Add to Home screen** (or **Install app**). From the home screen it opens full
screen, like an app, either way up. In a browser tab it goes full screen at the first tap; **☰ → Settings → Display →
Full screen** turns that off and on.

The game is saved on the device it is played on.

This repository holds only the built game; it is rebuilt from the sources elsewhere.
